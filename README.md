# Pomodoro Clock ⏰

A simple and responsive Pomodoro Clock built with HTML, CSS, and JavaScript to help improve productivity using the Pomodoro Technique.

## Features

- Start the timer
- Stop the timer
- Reset the timer
- Increase or decrease the session time
- Clean and responsive user interface
- Easy to use

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## How to Use

1. Adjust the session time using the **+** and **−** buttons.
2. Click **Start** to begin the countdown.
3. Click **Stop** to pause the timer.
4. Click **Reset** to return to the default time.

## Future Improvements

- Add short and long break modes
- Play a sound when the timer finishes
- Save timer settings using Local Storage
- Display desktop notifications
- Add Dark Mode
